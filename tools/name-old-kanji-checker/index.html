名前の旧字体・異体字を調べる

名前に含まれる旧字体・異体字候補を1文字ずつ確認するための参考ツールです。氏名・戸籍・公的書類では、必ず実際の登録字体を確認してください。

名前・戸籍の旧字体を確認するとき

齋藤・渡邊・濱田・髙橋など、名前に含まれる文字を入力すると、このサイトの旧字体データに基づいて旧字→新字、新字→旧字・異体字候補を確認できます。

このツールは候補確認用であり、戸籍上の正式な字体や氏名への使用可否を判定するものではありません。正式表記を確認する場合は、実際の戸籍・公的書類に加えて、法務局の戸籍統一文字情報も参照してください。
