防災備蓄リスト：水・食料・携帯トイレの必要量

備蓄は「防災専用品を買うこと」だけではありません。缶詰や乾パン、普段の食品、毛布など、家にある物を整理して不足分を確認できます。BichikuCheckでは家族の人数・備蓄日数と停電・断水・調理不可の条件を選び、不足する用途から備える物を探せます。

備蓄は何日分？　家族2人・7日間の例

国の防災情報では最低3日、できれば1週間分を案内しています。飲用・調理用水の目安は1人1日約3Lなので、2人で7日間なら42Lです。本ツールの初期目安では、主食は42食分、携帯トイレは70回分。食数だけで栄養の十分さは保証できず、必要量は体調・年齢・環境により変わります。

非常食だけでなく普段の食品も比較

アルファ米・乾パン・保存パンなどの非常食に加え、米、カップ麺、缶詰、オートミール、レトルト食品も候補です。ただし、加熱や安全な飲用水が必要な食品は停電・断水時に使えるとは限りません。主食と副菜は区別して、製品の調理方法と保存条件を確認してください。

段ボール・アルミシートなどの代用品は？

防災用品には、普段使いできる物や一時的な代用品があります。例えば床からの冷えにはマット、体の保温には毛布や寝袋が必要です。段ボールやアルミ保温シートは補助候補ですが、専用品と無条件に同等とは数えません。携帯トイレも袋だけではなく、凝固剤・設置・保管方法まで確認します。

無料備蓄チェックの使い方

  1. 人数・日数・停電・断水などの状況を入力します。
  2. 食料・水・トイレ・防寒など、用途別の不足を確認します。
  3. 家にある具体的な食品・用品の数と使用条件を登録します。
  4. 足りない品目だけを買い物リストとして保存・印刷できます。

参考：国の防災情報・備えのチェック、東京都の日常備蓄ガイド、消費者庁の調理器具・発電機の安全情報。本サイトは行政機関による公式判定ではなく、一般家庭向けの計画補助です。

使い方・判断基準・よくある質問

何を、どれだけ備える？

人数・日数・停電・断水・調理できない状況を選び、不足を「食料」「水」「トイレ」「寝具・防寒」などの用途別に確認します。食料は1人1日3食分、水は飲用・調理用として1人1日約3L、携帯トイレは1人1日5回を初期目安にしています。必要量は体調や環境で変わり、食数だけでは栄養は評価できません。

普段の食品でも非常食になる？

はい。乾パン、缶詰、レトルト食品に加えて、普段使いの保存食品も候補です。ただし、主食と副菜は別に考え、袋麺・カップ麺・オートミール等の加熱や水の必要性は商品表示を確認してください。

水で戻す食品はどう計算する？

食品ごとに、登録した全食数に必要な安全な飲用水量と調理方法を確認してください。水量が未確認の食品は、断水時の使用可能な備蓄として無条件には数えません。水は飲用・調理用の同じ備蓄から割り当てます。

アルミシートや段ボールはマットの代わり？

床の断熱と体の保温は別の目的です。段ボールやアルミシートは一時的・補助的な候補ですが、専用マットと毛布の両方を完全に置き換えるとは判定しません。

登録した情報や購入リンクはどうなる？

人数や所持数はこの端末のブラウザ内に保存されます。Amazonの検索リンクには固定の商品カテゴリ名だけを使い、人数や備蓄内容は送信しません。購入は任意で、価格・在庫・商品適合性を保証しません。災害時は自治体の最新情報を優先してください。
