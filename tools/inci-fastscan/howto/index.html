INCI FastScan：使い方

写真/OCRまたはテキストから成分表示を読み取り、確認してから辞書照合するためのガイドです。

このツールでできること

  • 商品ラベルの写真・画像を選び、ブラウザ上のOCRで成分表示を読み取る
  • OCR結果を自分で確認・修正してから成分名を照合する
  • 写真を使わず、INCI名や日本語成分表示を直接貼り付ける
  • ローカル辞書との照合結果を「辞書一致」「追加確認」「未一致」に整理する
  • 結果を状態で絞り込み、追加確認・未一致を順番にレビューする
  • 未一致の表記に近い候補がある場合、候補を確認して明示的に入力へ反映する

使い方

  1. 入力方法で「写真・画像から」または「テキストから」を選びます。初期状態は写真モードです。
  2. ラベルの言語で「INCI / 英語」または「日本語成分」を選びます。
  3. 写真モードでは画像を選択してOCRを実行し、読み取られた文字を必ず目視で確認・修正します。
  4. テキストモードでは成分表示をそのまま入力欄へ貼り付けます。
  5. 成分名を照合 を押して結果を表示します。
  6. 必要に応じて結果フィルター、確認対象の前後移動、未一致候補の反映を使います。

結果表示の意味

  • 辞書一致：入力した表記が、管理しているINCI名・日本語名・登録済み別名などと一致した状態です。
  • 追加確認：既存の辞書情報などから、さらに公式情報や使用条件を確認するための目印です。危険判定ではありません。
  • 未一致：現在の辞書で入力表記を特定できなかった状態です。安全・危険の意味はありません。

日本語成分タブは、日本語名や登録済み別名を辞書照合するためのものです。日本語を英語へ機械翻訳する機能ではありません。

OCRを使うときの注意

  • OCRは画像の画質、傾き、反射、文字サイズなどによって誤認識・欠落・行分割が起こります。
  • OCR結果はそのまま正しいものとして扱わず、商品ラベルと見比べて修正してください。
  • 候補表示はOCRや綴りの修正候補であり、自動的に成分を確定するものではありません。
  • 候補を入力へ反映しても解析は自動再実行されません。必要ならもう一度照合してください。

できないこと・限界

  • 成分や製品をSAFE / CAUTION / RISKのような安全性ランクで判定するツールではありません。
  • 成分の濃度、処方全体、個人差、アレルギー、妊娠中の適否、薬との相互作用、規制上の適否などは判定できません。
  • 医学的・皮膚科的な診断や、製品全体の安全性保証は行いません。
  • 辞書にない表記は、既知の成分でも未一致になる場合があります。

データと通信について

  • 選択した画像のプレビュー、OCR後の文字編集、成分照合、結果フィルターなどはブラウザ上で処理します。
  • OCRに使うTesseract.jsライブラリは外部CDN（unpkg.com）から読み込みます。そのためページ全体が完全オフラインで動作するわけではありません。
  • 成分テキスト・OCR結果・解析結果を履歴として保存する機能はありません。
  • UIの言語設定は、利用できる場合にブラウザ内へ保存されることがあります。

LiteとFastScanの使い分け

  • FastScan：写真/OCRから始めたい、または確認対象を詳しく追いたい場合
  • Lite：すでに全成分表示のテキストがあり、貼り付けて素早く整理したい場合
