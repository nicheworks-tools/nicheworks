NicheWorks Reconcile — Usage

このページは開発ブランチ用です。現在の実装波はCSVのローカル照合コアを対象とします。

Current workflow

  1. CSV A/Bを選択、またはサンプルを読み込みます。
  2. 金額列を必須で対応付け、必要なら日付・取引ID・摘要を選びます。
  3. 日付許容差を選び、照合します。
  4. exact / tolerant / candidate / A only / B only / duplicate / conflict を確認します。
  5. CSVで照合結果を保存できます。

Privacy

取引行はブラウザ内で処理します。この開発波のコードは取引データ送信用APIを持ちません。

Not implemented in this wave

XLSX、Pro entitlement、Stripe、1:n / n:1、金額許容差、ルール保存、XLSXレポートは後工程です。
