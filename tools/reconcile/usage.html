NicheWorks Reconcile — Usage

このページは開発ブランチ用です。CSV照合コアと高度照合エンジンは実装済みです。XLSXはアダプターまで実装済みですが、検証済みSheetJS CE 0.20.3 mini本体の同梱前なのでブラウザではまだ利用できません。Pro機能も課金接続前のためロックされています。

Free workflow

  1. CSV A/Bを選択、またはサンプルを読み込みます。
  2. 必要なら文字コード、区切り文字、ヘッダー行を調整します。
  3. 金額列を必須で対応付け、必要なら日付・取引ID・摘要を選びます。
  4. 日付許容差と曖昧日付の解釈を選び、照合します。
  5. exact / tolerant / candidate / A only / B only / duplicate / conflict を確認します。
  6. 結果をCSVで保存できます。

Matching rules

照合は決定論的です。Reference完全一致を優先し、その後もA/B双方から見て一意な1:1関係だけを自動確定します。複数の候補がある場合や複数A行が同じB行を取り合う場合は、入力順で勝手に割り当てずcandidateにします。同一参照IDでも金額差が許容範囲を超える場合はconflictとして扱います。

同額取引が大量に並ぶなど、1:1候補グラフが安全上限を超える場合は途中結果を自動確定せず照合を停止します。その場合は日付または取引ID/参照列を追加して候補を絞ります。1:n / n:1の組合せ探索にも別の探索上限があり、上限到達時は自動一致せずmanual review候補へ落とします。

Reconcile Pro implementation

Pro用の金額許容差、B側符号反転、符号無視、1:n / n:1照合、最大5件のグループ照合、XLSXレポート、保存済みルールのコードとUIは実装済みです。ただしこの隔離ブランチではentitlementを接続していないため、操作はロックされています。

保存済みルールは列対応・CSV解析設定・照合条件だけをlocalStorageへ保存します。取引行、ファイル本体、照合結果は保存しません。ルールは最大20件で、JSONとしてimport/exportできます。

XLSX status

複数worksheetの選択、Excel日付/数値の読み込み、Summary / Matches / Candidates / A Only / B Only / Duplicates / Conflicts の7シートレポート生成まで実装済みです。SheetJS CE 0.20.3のmini buildを固定し、ランタイムCDNは使用しません。ライセンスとchecksum契約は同梱済みで、残りはSHA-256検証済みJS本体のvendor commitと実ブラウザread/write確認です。

Privacy

取引行はブラウザ内で処理します。この開発ブランチのコードは取引データ送信用APIを持ちません。公開時の課金通信もentitlement情報のみを扱い、取引ファイルは送信対象にしません。

Current limits

Freeは1ファイル500行・5MBまでです。Pro有効時の現在のブラウザ安全上限は1ファイル100MBで、行数に固定上限は設けません。ただしブラウザメモリに加え、1:1候補グラフと1:n / n:1探索には明示的な安全予算を設けています。大きいだけではなく候補が極端に曖昧なデータも、安全側で停止します。
