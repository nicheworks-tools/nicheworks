NicheWorks Reconcile — 使い方

2つのCSV/XLSX取引データをブラウザ内で照合し、完全一致だけでなく候補・重複・不一致など、人が確認すべき例外を抽出するツールです。取引ファイルや取引行はNicheWorksサーバーやStripeへ送信しません。

Free workflow

  1. File A / File BとしてCSVまたはXLSXを選択します。
  2. CSVの場合は必要に応じて文字コード、区切り文字、ヘッダー行を調整します。XLSXの場合はworksheetを選択できます。
  3. 金額列を必須で対応付け、必要なら日付・取引ID/Reference・摘要を選びます。
  4. Freeでは日付許容差を0日または±1日から選び、照合します。
  5. exact_match / tolerant_match / candidate / a_only / b_only / duplicate / conflict を確認します。
  6. 監査結果をCSVで保存できます。

Matching rules

照合は決定論的です。Reference完全一致を優先し、その後もA/B双方から見て一意な1:1関係だけを自動確定します。複数候補がある場合や複数A行が同じB行を取り合う場合は入力順で勝手に割り当てず、candidateとして人の確認対象に残します。同一Referenceでも金額差が許容範囲を超える場合はconflictとして扱います。

同額取引が大量に並ぶなど1:1候補グラフが安全上限を超える場合は、途中結果を勝手に確定せず照合を停止します。その場合は日付やReference列を追加して候補を絞ってください。1:n / n:1の組合せ探索にも別の安全上限があります。

Reconcile Pro

Reconcile Proは¥3,980 JPYのone-time商品です。CSVは1ファイル100,000行・50MBまで、XLSXは1ファイル50,000行・25MBまで扱えます。金額許容差、B側符号反転、符号無視、1:n / n:1照合、最大5件のグループ照合、7-sheet XLSX audit report、保存済みルール、ルールJSON import/exportを追加します。

Reconcile Pro購入ではReconcile専用権利に加えてNicheWorks共通Proも付与されます。一方、NicheWorks共通Proだけを持っていてもReconcile Proは解錠されません。Reconcile側は専用権利をサーバーで確認し、確認できない場合はFreeのまま動作します。

Saved rule profiles

Proの保存済みルールは列対応・CSV解析設定・照合条件だけをlocalStorageへ保存します。取引行、ファイル本体、照合結果は保存しません。最大20件まで保存でき、JSONとしてimport/exportできます。保存した列名が新しいファイルに存在しない場合は、その列を勝手に置き換えず未選択に戻します。

XLSX

複数worksheetの選択、Excel日付/数値の読み込み、Summary / Matches / Candidates / A Only / B Only / Duplicates / Conflicts の7シート監査レポート生成に対応します。SheetJS CE 0.20.3 miniをローカルvendorとして固定しており、XLSX処理のためのランタイムCDNは使用しません。

Privacy

CSV/XLSXの解析、正規化、照合、監査結果生成はブラウザ内で行います。取引データ、取引行、摘要、金額、Reference、ファイル本体をNicheWorksサーバーやStripeへ送信しません。課金時の通信はcheckout作成とentitlement確認に必要な商品・権利情報に限られます。

Limits

FreeはCSV/XLSXとも1ファイル500行・5MBまでです。Reconcile ProはCSVが1ファイル100,000行・50MBまで、XLSXが1ファイル50,000行・25MBまでです。unlimitedではありません。さらに1:1候補グラフと1:n / n:1探索には安全上限があります。
