現在の公開ルール要点

Current publishing rules

  • Cloudflare Pages：build commandとoutput directoryを設定できます。ビルド不要ならBuild commandを空欄にもでき、静的HTMLガイドではpresetを使わない場合のno-build commandとしてexit 0が案内されています。
  • Cloudflare Pages: configure a build command and output directory. A no-build site may leave the build command blank; Cloudflare's static HTML guide also documents exit 0 when no preset/build is required.
  • Cloudflare Direct Upload：dashboardのdrag-and-dropでは/functions directoryをcompileできません。Functionsを使う場合はWrangler等を確認してください。Direct Upload projectは後からGit integrationへ切り替えできません。
  • Cloudflare Direct Upload: dashboard drag-and-drop does not compile a /functions directory. Use Wrangler or another supported flow for Functions. A Direct Upload project cannot later be switched to Git integration.
  • GitHub Pages：branch公開のsource folderは/または/docsのみです。dist/public等のbuild成果物はGitHub ActionsでPages artifactとしてdeployできます。
  • GitHub Pages: branch publishing supports only / or /docs as the source folder. Built output such as dist/public can be deployed as a Pages artifact with GitHub Actions.
  • GitHub custom domain：custom domainはPages設定/APIで登録します。branch公開ではCNAME fileが使われますが、custom Actions workflowではCNAME fileは不要で無視されます。
  • GitHub custom domain: configure the domain in Pages settings/API. Branch publishing uses a CNAME file, while a custom Actions workflow does not require it and ignores it.

FAQ

このチェックだけでデプロイ成功を保証できますか？

いいえ。公開前確認の補助です。実際のビルドログ、表示、DNS/SSL、各サービスの公式ドキュメントを確認してください。

GitHub Pagesでdistやpublicを選べますか？

branch公開のsource folderは /(root) または /docs のみです。dist/public等のbuild成果物を使う場合はGitHub ActionsでPages artifactをdeployする方法を確認してください。

症状別診断やMarkdown出力は有料ですか？

いいえ。症状別診断、引き継ぎパック、全結果コピー、Markdown保存を含め、現在の機能は無料です。
