用途・確認ポイント / Uses & key points

接着剤や薄塗りモルタルを一定量・一定形状で塗り広げるくし目付きコテ。タイル寸法、下地、材料に応じて切欠き形状と大きさを選ぶ。

A trowel with notched edges used to spread adhesive or thin-set mortar in controlled ridges. Notch shape and size should suit tile size, substrate, and setting material.

  • 材料メーカー・タイル寸法に合うくし目サイズを使用する。
  • 一定角度で引いて均一なリッジを作り、皮張りした材料へ貼り付けない。
  • 必要に応じ裏面充填を確認し、施工後は固着前に工具を清掃する。
  • Use the notch size recommended for the material and tile dimensions.
  • Hold the trowel at a consistent angle to form uniform ridges and do not set tile into skinned-over material.
  • Check coverage where required and clean the trowel before material hardens.

よく使われる場面 / Examples

  • 大型タイル用接着剤を指定くし目で塗布する。
  • 床タイル施工で一定方向のリッジを作る。
  • Spread tile adhesive with the specified notch for large-format tile.
  • Comb mortar in a consistent direction during floor-tile installation.
