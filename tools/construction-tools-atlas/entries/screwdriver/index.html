これは何？ / What is it?

手作業でネジを締めたり緩めたりする工具。 用途に応じて締付けトルクや長さを選ぶ。 部材同士を固定してガタつきを防ぐ。

A hand tool for tightening or loosening screws. Over-tightening can strip or crack materials. Select length and torque appropriate for the job.

用途・確認ポイント / Uses & key points

ねじを手作業で締めたり緩めたりする工具。プラス、マイナス、トルクスなど先端規格とサイズをねじ頭に合わせ、柄の形状や軸長を作業空間に応じて選ぶ。

Hand tool used to tighten or loosen screws. Tip pattern and size such as Phillips, slotted, or Torx must match the screw head, while handle shape and shaft length should suit the workspace.

  • ねじ頭へ適合する先端規格・サイズを使い、浮いた状態で回さない。
  • 先端が摩耗・欠けした工具はカムアウトやねじ頭損傷の原因になるため交換する。
  • 電気作業では必要に応じて定格絶縁工具を使用し、一般ドライバーを絶縁品として扱わない。
  • Use the correct tip pattern and size and keep it fully seated in the screw head.
  • Replace worn or chipped tips that increase cam-out and screw-head damage.
  • For electrical tasks, use appropriately rated insulated tools when required rather than assuming an ordinary screwdriver is insulated.

よく使われる場面 / Examples

  • 配線器具の取付ねじを適合するプラスドライバーで締める。
  • 点検カバーのねじを手作業で外す。
  • Tighten a wiring-device screw with the correct Phillips screwdriver.
  • Remove inspection-cover screws by hand.
