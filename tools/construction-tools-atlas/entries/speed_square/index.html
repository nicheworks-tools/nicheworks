これは何？ / What is it?

直角や寸法、勾配の確認に使うL字型の測定工具。大工仕事や現場加工で、墨付け、直角確認、切断線の作図に使う。落下や曲がりで精度が狂うことがある。

An L-shaped measuring tool used for right angles, dimensions, and slope layout. It is common in carpentry and site fabrication for marking, checking square, and drawing cut lines. Accuracy can be affected by bending or impact.

用途・確認ポイント / Uses & key points

長手と短手を材料の基準面に密着させて線を引く。曲がった差し金では直角が狂う。表裏の目盛りや勾配目盛りを使い分ける場合は読み間違いに注意する。

Hold the long and short legs tight against the reference edges before marking. A bent square gives inaccurate angles. When using front/back scales or pitch scales, avoid reading the wrong scale.

  • 曲がりに注意。
  • 基準面に当てる。
  • Check for bending.
  • Use a reference edge.

よく使われる場面 / Examples

  • 木材に直角の切断線を引く。
  • 造作部材の矩を確認する。
  • Marking a square cut line on lumber.
  • Checking a finish component for square.

別名・呼び方 / Aliases

日本語: 曲尺、さしがね、矩尺

English: Carpenter Square
