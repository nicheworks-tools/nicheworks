これは何？ / What is it?

レーザーで壁・床・天井までの距離を測る工具。室内寸法、開口、天井高さの確認に使う。反射面や斜め測定で誤差が出るため、重要寸法はスケールでも確認する。

A laser tool for measuring distance to walls, floors, and ceilings. It is used for room dimensions, openings, and ceiling heights. Reflective surfaces and angled readings can cause errors, so verify critical dimensions with a tape measure.

用途・確認ポイント / Uses & key points

本体の基準位置が後端・前端・三脚基準のどれかを確認して使う。斜めに当てると実寸より長く出る。ガラス、黒い面、強い日光下では測定エラーが出やすい。

Confirm whether the reference point is the rear, front, or tripod position. Angled readings are longer than true dimensions. Glass, dark surfaces, and strong sunlight can cause errors.

  • 基準位置確認。
  • 斜め測定注意。
  • Check reference point.
  • Avoid angled readings.

よく使われる場面 / Examples

  • 室内の壁間寸法を測る。
  • 天井高さを確認する。
  • Measuring room width.
  • Checking ceiling height.

別名・呼び方 / Aliases

日本語: 距離計、レーザーメジャー

English: Laser measure, Laser distance measurer
