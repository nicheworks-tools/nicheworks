用途・確認ポイント / Uses & key points

「断熱材」：建材・資材の呼び方。用途や規格は製品で異なる。

Insulation: A material/building supply term. Specs vary by product.

  • 設計で指定された種類・厚さを用い、隙間や大きな圧縮を避けて連続して施工する。
  • 繊維系材料では皮膚・眼・呼吸器への刺激を抑える保護具と換気を行う。
  • 熱源、照明器具、配線、通気層との離隔は製品・法令・設計条件に従う。
  • Install the specified type and thickness continuously without gaps or excessive compression.
  • For fibrous products, use ventilation and protective equipment to limit skin, eye, and respiratory irritation.
  • Maintain required clearance from heat sources, luminaires, wiring, and ventilation spaces according to product, code, and design requirements.

よく使われる場面 / Examples

  • 壁の間柱間へグラスウール断熱材を隙間なく充填する。
  • 屋根裏へ所定厚の断熱材を連続して施工する。
  • Fit glass-fiber insulation between wall studs without gaps.
  • Install the specified insulation thickness continuously across an attic.
