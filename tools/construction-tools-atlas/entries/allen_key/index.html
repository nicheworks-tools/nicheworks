用途・確認ポイント / Uses & key points

「六角レンチ」：建設現場で使う用語。文脈により意味が変わることがある。

Allen key: A construction term. Meaning may vary by context.

  • ミリ・インチを含め正しいサイズを選び、角が摩耗した工具を使わない。
  • ボルト穴へ十分に差し込み、斜め掛けや過大な延長で六角穴を傷めない。
  • 指定トルクがある箇所では通常のL形レンチだけで管理せず、適切なトルク工具を使う。
  • Select the correct metric or inch size and do not use a rounded or damaged key.
  • Seat the key fully in the socket and avoid angled engagement or excessive leverage that can strip the fastener.
  • Where a specified torque is required, use an appropriate torque-controlled tool rather than relying on a basic L-key.

よく使われる場面 / Examples

  • 設備カバーの六角穴付きボルトを六角レンチで取り外す。
  • 家具金物の止めねじを適正サイズのヘックスキーで締める。
  • Remove socket-head screws from an equipment cover with a hex key.
  • Tighten a set screw in hardware with the correctly sized Allen key.
