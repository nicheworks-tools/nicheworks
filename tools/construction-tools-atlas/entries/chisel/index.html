これは何？ / What is it?

木材を削る、ほぞ穴を整える、細部を加工するための刃物工具。木工や造作で使う。刃先が鋭いため、手の位置と切る方向に注意し、叩く場合は適した柄とハンマーを使う。

A bladed hand tool for paring wood, cleaning mortises, and shaping details. It is used in carpentry and finish work. Because the edge is sharp, keep hands out of the cutting path and use the proper handle and mallet when striking.

用途・確認ポイント / Uses & key points

刃を研いで使い、無理にこじらない。節や硬い材料では刃が欠けることがある。作業台や材料を固定し、刃の進む先に手を置かない。

Use it sharp and do not pry with the edge. Knots and hard materials can chip the blade. Secure the workpiece and keep hands away from the cutting direction.

  • 刃物の向きに注意。
  • 固定して作業。
  • Watch blade direction.
  • Secure the work.

よく使われる場面 / Examples

  • 建具枠の細部を削る。
  • 木材の欠き込みを整える。
  • Paring a door-frame detail.
  • Cleaning a notch in wood.

別名・呼び方 / Aliases

日本語: 鑿、木工のみ

English: Wood chisel, Carpenter chisel
