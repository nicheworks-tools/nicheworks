これは何？ / What is it?

回転に細かい打撃を加えて、モルタルやブロックなどに穴をあける電動工具。軽めのコンクリート穴あけに使う。大径穴や本格的なコンクリート作業ではハンマードリルを使う。

A drill that adds rapid hammering action to rotation for drilling mortar, block, and light concrete. For larger holes or heavier concrete work, use a rotary hammer.

用途・確認ポイント / Uses & key points

プラグアンカーや軽量物の固定下穴に使う。鉄筋に当たると進まないため、無理に押し続けない。粉じん対策、保護メガネ、適切なコンクリート用ビットが必要。

Used for plug anchors and light-duty fixing holes. If it hits rebar, do not force it. Dust control, safety glasses, and a proper masonry bit are needed.

  • 粉じん対策を行う。
  • ビット選定が重要。
  • Use dust control.
  • Select the correct bit.

よく使われる場面 / Examples

  • コンクリート壁にプラグ用の下穴をあける。
  • ブロック塀に軽量金物を固定する。
  • Drilling a plug-anchor hole in a concrete wall.
  • Fixing light hardware to a block wall.

別名・呼び方 / Aliases

日本語: 震動ドリル、コンクリートドリル

English: Percussion drill, Impact drill
