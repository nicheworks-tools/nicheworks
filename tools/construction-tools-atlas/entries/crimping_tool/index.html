これは何？ / What is it?

端子を電線に圧着して確実に接続する工具。 規格や資格要件がある作業もある。

A tool that crimps terminals onto wires for secure connections. Some tasks require codes compliance or certification. Used for wiring and electrical installation.

用途・確認ポイント / Uses & key points

電線へ圧着端子やスリーブを規定形状で圧着する工具。端子種類、電線サイズ、ダイス形状、ラチェット機構を接続仕様に合わせて選ぶ。

Tool used to crimp terminals or sleeves onto conductors with the required profile. Terminal type, wire size, die geometry, and ratchet mechanism must match the connection system.

  • 端子と電線サイズに適合するダイスを使用する。
  • 圧着位置を正しく合わせ、途中で解除せず規定ストロークまで圧着する。
  • 電気作業は必要な資格・手順に従い、回路状態を確認してから行う。
  • Use a die matched to the terminal and conductor size.
  • Position the terminal correctly and complete the full crimp cycle rather than stopping partway.
  • Follow applicable electrical-work qualifications and procedures and verify circuit condition before work.

よく使われる場面 / Examples

  • リング端子をより線へ規定ダイスで圧着する。
  • 圧着後に端子の抜けや変形を目視確認する。
  • Crimp a ring terminal onto stranded wire with the specified die.
  • Inspect the completed crimp for pullout or abnormal deformation.

別名・呼び方 / Aliases

日本語: 圧着ペンチ

English: Crimper
