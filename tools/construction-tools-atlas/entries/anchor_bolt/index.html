これは何？ / What is it?

コンクリート等に固定するためのアンカー付きボルト。 締め過ぎは破損の原因になる。 部材同士を固定してガタつきを防ぐ。 構造物や設備をコンクリート等へ固定するためのアンカーボルト。方式、径、埋込み長さ、母材強度、端距離を必要荷重と施工条件に合わせる。

A bolt/anchor system used to fasten items to concrete or masonry. Over-tightening can strip or crack materials. Anchor bolt used to secure structures or equipment to concrete or similar substrates. Anchor type, diameter, embedment, concrete strength, and edge distance must suit the design load and installation conditions.

用途・確認ポイント / Uses & key points

構造物や設備をコンクリート等へ固定するためのアンカーボルト。方式、径、埋込み長さ、母材強度、端距離を必要荷重と施工条件に合わせる。

Anchor bolt used to secure structures or equipment to concrete or similar substrates. Anchor type, diameter, embedment, concrete strength, and edge distance must suit the design load and installation conditions.

  • 設計・メーカー仕様に従い径、埋込み、孔径、端距離を守る。
  • 穿孔後は指定手順で孔内清掃を行い、所定位置へ施工する。
  • 所定の締付けや養生完了前に荷重を掛けない。
  • Follow design and manufacturer requirements for diameter, embedment, hole size, and edge distance.
  • Clean drilled holes as specified before installing the anchor.
  • Do not load the anchor before required tightening or curing is complete.

よく使われる場面 / Examples

  • 設備架台をコンクリート床へアンカー固定する。
  • 柱脚金物のアンカー位置を施工図に合わせて確認する。
  • Anchor an equipment frame to a concrete floor.
  • Verify column-base anchor locations against the installation drawing.
