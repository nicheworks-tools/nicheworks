これは何？ / What is it?

高所作業のための昇降用具。安定設置が重要。 安定した足場を確保して使う。 無理な体勢は事故の元。

A climbing device for working at height; proper placement is critical. Use on stable footing. Avoid overreaching to prevent falls. Ladder used for access to elevated locations. Straight and extension types vary in length, material, duty rating, and setup requirements that should suit the work height and environment.

用途・確認ポイント / Uses & key points

高所へ昇降するためのはしご。単はしご、伸縮式などがあり、長さ、材質、定格荷重、設置角度を作業高さと環境に合わせて選ぶ。

Ladder used for access to elevated locations. Straight and extension types vary in length, material, duty rating, and setup requirements that should suit the work height and environment.

  • 水平で安定した支持点へ設置し、適切な角度と上端支持を確保する。
  • 最上段付近で無理に身体を乗り出さず、三点支持を意識する。
  • 脚、桟、ロック、滑り止めに損傷がある場合は使用しない。
  • Set the ladder on stable support with the appropriate angle and secure upper support as required.
  • Avoid overreaching near the top and maintain three points of contact when climbing.
  • Do not use a ladder with damaged feet, rungs, locks, or anti-slip parts.

よく使われる場面 / Examples

  • 屋上点検口へ安全に昇降するため伸縮はしごを設置する。
  • 壁面の軽作業位置へ単はしごでアクセスする。
  • Set an extension ladder for safe access to a roof hatch.
  • Use a straight ladder to reach a light-duty wall work location.

別名・呼び方 / Aliases

日本語: 脚立(用途による)、はしご

English: Step Ladder, Ladder, A-frame ladder
