これは何？ / What is it?

電線の被覆を傷つけずに剥く工具。 規格や資格要件がある作業もある。

A tool for removing insulation from electrical wires without damage. Some tasks require codes compliance or certification. De-energize and verify before touching conductors.

用途・確認ポイント / Uses & key points

電線導体を傷つけずに被覆を所定長さだけ除去するための工具。電線サイズ、単線・より線、自動調整式か穴径式かなどを対象ケーブルに合わせて選ぶ。

Tool used to remove a controlled length of insulation without damaging the conductor. Wire size, solid or stranded construction, and stripper mechanism must match the cable.

  • 作業前に回路を無電圧化し、必要な手順で確認してから導体へ触れる。
  • 電線サイズに合う刃・穴を使い、導体へ切り傷を付けない。
  • 端子仕様に必要な剥き長さを守り、被覆を過剰に除去しない。
  • De-energize the circuit and verify the safe condition before handling conductors.
  • Use the stripping position or blade setting for the wire size so conductor strands are not nicked.
  • Strip only the length required by the terminal specification and avoid excessive exposed conductor.

よく使われる場面 / Examples

  • 圧着端子施工前により線の被覆を指定長さだけ剥く。
  • 盤内配線の端末処理で電線サイズに合う穴を選ぶ。
  • Strip the specified length of insulation before crimping a terminal.
  • Select the correct stripping slot for a conductor during panel wiring.

別名・呼び方 / Aliases

English: Stripper
