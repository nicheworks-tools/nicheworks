これは何？ / What is it?

重りを糸で吊り、重力で垂直を確認する。 当て方で誤差が出るので面を清掃して測る。

A weight on a string used to check vertical alignment. Surface debris can skew readings—clean contact points. Tool consisting of a weight suspended from a line to establish a true vertical reference by gravity. Weight, line length, and point shape should suit the height and environmental conditions.

用途・確認ポイント / Uses & key points

糸の先に重りを吊り、重力方向を利用して垂直基準を出す工具。重りの重量、糸長、先端形状を測定高さや風などの現場条件に合わせて使う。

Tool consisting of a weight suspended from a line to establish a true vertical reference by gravity. Weight, line length, and point shape should suit the height and environmental conditions.

  • 上部の吊り点を確実に固定し、重りが自由に静止できる空間を確保する。
  • 風や振動がある場合は振れが収まってから読み取る。
  • 重りの真下へ人や壊れやすい物を置かない。
  • Secure the upper suspension point and provide clear space for the weight to hang freely.
  • Allow movement from wind or vibration to settle before taking a reading.
  • Keep people and fragile objects out from directly below the suspended weight.

よく使われる場面 / Examples

  • 柱の上下位置を比較して垂直を確認する。
  • 上階の基準位置を下階へ鉛直に移す。
  • Compare top and bottom positions of a column to check plumb.
  • Transfer a reference point vertically from an upper level to a lower one.

別名・呼び方 / Aliases

English: Plumb Line Weight, Plummet
