# UI Mock v2 CI scope

The dedicated `Construction Tools Atlas UI Mock v2` workflow is a contract gate for the parity layer. It verifies JavaScript syntax, the accepted desktop/mobile structural contract, canonical image-registry usage, fail-closed canonical affiliate mapping, reuse of the shared Amazon helper, and retirement of the obsolete one-column design specification.

It complements, rather than replaces, the existing Construction Tools Atlas data and audit workflows.
