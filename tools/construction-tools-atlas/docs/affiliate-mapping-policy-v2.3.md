# Construction Tools Atlas affiliate mapping policy v2.3

Amazon links are optional commerce handoffs attached to canonical dictionary entries. They are not dictionary evidence and must never be inferred directly from user search text.

An entry is eligible only when a maintained mapping exists in `data/affiliate-offers-v2.3.json`. The mapping must identify the canonical `entry_id`, a stable maintained query, an HTTPS Amazon Japan URL, the active NicheWorks tracking ID, and user-facing JA/EN labels. Entries without an approved mapping render no Amazon surface.

Task names, slang, ambiguous terms, and non-purchasable concepts are fail-closed by default. Future mapping waves require explicit eligibility review before activation.
