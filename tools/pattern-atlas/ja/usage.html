Pattern Atlas の使い方

模様の探し方、色編集、素材出力、文化的注意についての説明ページです。

English version

このツールでできること

Pattern Atlasは、現在の模様カタログを検索し、意味や文化的背景を確認しながら、色を編集し、描画結果をプレビューしてSVG / PNG / CSS素材として書き出せるツールです。

基本の流れ

  1. 検索またはフィルタで模様を探します。
  2. 意味・地域・用途・注意点を確認します。
  3. 色を変更し、現在の描画結果をプレビューします。
  4. SVG / PNG / CSS形式で書き出します。文化的注意が設定された模様では、出力前に確認チェックが必要です。

出力形式

SVG は拡大しても劣化しにくいベクター形式です。

PNG は選択したサイズでブラウザ内生成されます。

CSS はSVG data URIを使った繰り返し背景用コードとして生成されます。

文化的注意

このツールの模様は、伝統・地域・民族・宗教的背景を持つ文様を参考にする場合があります。出力素材は公式な歴史復元や文化的認証素材ではありません。商用利用や公的利用では、必要に応じて追加調査を行ってください。

処理と保存範囲

カタログ検索、描画、色編集、PNG変換、CSS生成、ダウンロードは同一サイトのコード・模様データを使ってブラウザ内で処理します。検索条件、選択中の模様、色編集は現在ページの状態で、現行版にアカウント同期型の保存ライブラリやpalette履歴はありません。広告・アクセス解析resourceは別途読み込まれる場合があります。

FAQ

出力した素材は自由に使えますか？
無条件の自由利用を保証するものではありません。各模様の注意・文脈を確認し、用途に応じて権利や文化的背景を追加確認してください。

このサイトの模様は歴史的に正確な復元ですか？
いいえ。原則として、伝統文様等に着想を得た現代的な再構成として扱います。

利用者の模様ファイルはサーバーに送られますか？
現行の検索・編集・プレビュー・出力に画像やデザインファイルのアップロードは不要です。これらの処理はブラウザ内で行い、広告・アクセス解析resourceは別途読み込まれる場合があります。
