EN 旧字体検索

旧字体の調べ方

1文字を調べるなら検索、画像しかないならOCR、文章全体なら変換ツールを使い分けます。

最短の調べ方

普段使っている字体が分かるなら、その1文字を旧字体検索に入れるのが最短です。

  1. 旧字体検索・旧字体一覧を開く
  2. 検索欄に普段の字体、または手元にある旧字体を1文字入力する
  3. 表示された旧字・新字の対応を確認し、必要な文字をコピーする
旧字体を検索する

普段の字しか分からない場合

たとえば現在の「画」しか分からない場合でも、検索欄に「画」と入れて対応する旧字体を探せます。Old Kanji Reference は旧字体だけでなく、現在の字体・読み・意味・Unicodeでも一覧を絞り込めます。

個別解説がある文字：画 / 畫、将 / 將、旧 / 舊

画像や紙にしか旧字体がない場合

写真、スキャン画像、古い紙資料などで文字を直接入力できない場合は、Old Kanji OCR Scannerで画像から文字を読み取り、その結果を旧字体検索で確認します。

旧字体OCRを開く 読み取った文字を検索する

OCR結果は画像品質や字体によって誤認識することがあります。候補が出たら、最終的な字体は検索結果と元画像を見比べて確認してください。

文章全体を旧字体・新字体へ変換したい場合

1文字の確認ではなく文章全体を変換したい場合は、リファレンスではなくKanji Modernizerを使います。Old Kanji Reference は文字の対応確認、Kanji Modernizer は文章変換という役割分担です。

文章変換ツールを開く

見つからないときの確認順

  1. 検索語を1文字だけにして再検索する
  2. 旧字体ではなく、異体字・互換漢字など別の関係ではないか確認する
  3. 画像しかない場合はOCRで文字候補を取得する

旧字体と新字体が必ず一対一で対応するわけではありません。検索結果が自己写像になる文字や、旧字体とは別の種類の字体関係もあります。

戸籍や公的書類で確認する場合

このサイトは字体を調べるための参照ツールです。戸籍、登記、申請書などで使用する正式な表記は、提出先や原資料の指定を優先してください。
