Old Kanji Reference / 個別文字

「画」の旧字体は「畫」

「計画」を旧字体で書くと「計畫」です。文化庁の常用漢字表では、現代の「画」に対して括弧内に「畫」が掲載されています。

画現在の字体 / U+753B
←
畫旧字体 / U+756B

読みと基本情報

読みガ・カク
対応畫 → 画
画のUnicodeU+753B
畫のUnicodeU+756B

NicheWorks収録データでは「畫」を「画」の旧字体として扱い、読みは「が・かく」、意味は「え・区切り・計画」としています。

「計画」の旧字体

「計画」の「画」だけを旧字体に置き換えると、計畫になります。文化庁の常用漢字表でも「画（畫）」の項目の例語として「計画」が掲載されています。

常用漢字表そのものが「計畫」という語形を例として掲載している、という意味ではありません。表で示された文字対応を「計画」に適用した表記例です。

根拠と注意

  • 文化庁「常用漢字表」 — 「画（畫）」、読み「ガ・カク」、例語「計画」などを確認できます。
  • Unicode Character Code Charts — 画と畫は別々のCJK統合漢字コードポイントとして収録されています。

人名・地名・公的書類では、一般的な旧字体対応だけで実際の登録字体を断定できない場合があります。必要な場合は原資料や提出先の指定を確認してください。
