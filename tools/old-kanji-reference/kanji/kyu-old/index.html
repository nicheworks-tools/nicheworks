旧字体検索・旧字体一覧 / 旧・舊

「旧」の旧字体は「舊」

現在の「旧」に対応する旧字体は、「舊」です。

舊
旧字体
→
旧
現在の字体

「旧」を旧字体で書くと

旧道 → 舊道

新旧 → 新舊

復旧 → 復舊

上の例は、「旧」の部分だけを対応する旧字体「舊」に置き換えたものです。現在一般に使われる字体は「旧」です。

「旧」と「舊」の根拠

文化庁の「常用漢字表（平成22年内閣告示第2号）」では、旧（舊）として掲げられています。同表では、丸括弧内の字体を、明治以来の活字の字体とのつながりを示すために参考として添えています。
