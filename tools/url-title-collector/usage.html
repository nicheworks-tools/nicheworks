URL Title Collector の使い方

URL Title Collector は、複数のURLをまとめて貼り付けるだけで、 <title> タグを高速取得できる超軽量ツールです。

通信について：「タイトルを取得する」を押すと、各入力URLはNicheWorks Cloudflare Workerへ送信されます。Workerが対象ページのHTMLを取得し、そのHTMLからブラウザ側で<title>を抽出します。

1. 使い方（3ステップ）

  • ① テキストエリアに URL を 1 行ずつ貼り付けます
  • ② 「タイトルを取得する」を押します
  • ③ URL とタイトル・ステータスが一覧で表示されます

結果は CSV / TSV 形式でコピーできます。リセットボタンで初期状態に戻ります。

2. ステータスの種類

  • success：タイトル取得に成功
  • no-title：ページ取得は成功したが <title> が存在しない
  • http-error：HTTPエラー（404 / 500 など）
  • network-error：DNS、接続拒否、取得失敗などネットワーク側の問題

3. 対応しているケース

  • 通常のHTMLページ
  • ニュースサイト・ブログなどの静的なページ
  • <title> タグを持つページ

4. 非対応のケース

  • ログインが必要なページ
  • PDF / JSON / XML など HTMLでないURL
  • Workerからの取得を拒否するサイト
  • JavaScriptで動的に <title> を変更するサイト

5. CSV / TSV 出力

結果テーブルはそのまま CSV（カンマ） / TSV（タブ） 形式でコピーできます。 Excel / Google Sheets / Notion などに貼り付け可能です。

6. よくある質問（FAQ）

Q：404でもタイトルが返ることがある？
独自の404ページ（Not Found HTML）が返され、そのHTML内の <title> を取得しているためです。

Q：一部サイトで失敗する理由は？
取得先がWorkerからのrequestを拒否する、DNS/接続で失敗する、HTMLを返さない等の理由があります。

Q：大量URLの上限は？
100〜300件程度が目安ですが、Workerや取得先サイト、通信状況、端末性能に依存します。

7. 免責・データ送信

入力URLはページ取得のためNicheWorks Cloudflare Workerへ送信され、Workerから対象サイトへrequestされます。 URLや取得結果をこのツールが履歴として保存する仕様ではありませんが、Worker・取得先サイト・通常の解析/広告resourceとの通信は発生します。 取得できないURLが存在する場合があります。
