How to Use URL Title Collector

URL Title Collector lets you fetch <title> tags from multiple URLs at once.

Network behavior: When you click “Fetch Titles,” each entered URL is sent to a NicheWorks Cloudflare Worker. The Worker requests the target page HTML, and the browser extracts the <title> from the returned HTML.

1. Basic Steps

  • ① Paste URLs into the text area, one per line
  • ② Click “Fetch Titles”
  • ③ URL, title, and status results appear in a table

Results can be copied as CSV or TSV. You can reset the tool at any time.

2. Status Types

  • success — title fetched successfully
  • no-title — page fetched but no <title> was found
  • http-error — target returned a 404, 500, or another non-success HTTP status
  • network-error — DNS, connection, Worker, or retrieval failure

3. Supported Cases

  • Standard HTML pages
  • Blogs and news articles
  • Pages with a server-returned <title> tag

4. Not Supported

  • Login-required pages
  • PDF / JSON / XML and other non-HTML resources
  • Sites that reject retrieval from the Worker
  • Sites where JavaScript changes the title only after page execution

5. CSV / TSV Output

The result table can be copied as CSV or TSV for use in Excel, Google Sheets, Notion, and similar tools.

6. FAQ

Q: Why does a 404 page sometimes return a title?
The target may return a custom Not Found HTML page that still contains a <title> tag.

Q: Why do some sites fail?
The target may reject requests from the Worker, fail at DNS or connection time, or return content that cannot be retrieved as normal HTML.

Q: How many URLs can I process?
Roughly 100–300 is a practical guideline, but actual behavior depends on the Worker, target sites, network conditions, and your device.

7. Disclaimer and data transmission

Entered URLs are sent to a NicheWorks Cloudflare Worker so the Worker can request the target pages. The tool does not keep a URL/result history, but network requests occur between your browser and the Worker, between the Worker and target sites, and through normal analytics or advertising resources loaded by the page. Some URLs may not be retrievable.
