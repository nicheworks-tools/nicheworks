# Screenshot Canvas v0.1

- Client-side canvas image compositor, no network upload.
- PNG/JPEG/WebP import via picker, drag/drop, paste.
- Move, proportional resize, multi-select, duplicate, delete, layer order.
- Horizontal, vertical, grid, overlay arrangements.
- Canvas dimensions, background, opacity, PNG export, undo/redo, JP/EN.
- Does not crawl or capture websites; does not replace Screenshot Stitcher.
