洗濯物が乾くか判定（Dry Meter）Laundry Drying Conditions Checker (Dry Meter)

気温・湿度・風速などから、洗濯物・厚手衣類・布団が今どれくらい乾きやすいかを確認します。

Check how favorable the current temperature, humidity, wind and weather are for drying laundry, thick items and bedding.

/

Dry Meterは湿度計・水分計そのものではなく、現在の天気データまたは手動入力した気温・湿度・風速から、洗濯物が「いま乾きやすいか」をDry Scoreで判定するツールです。外干し・部屋干し・厚手衣類・布団の目安に使えます。

Dry Meter is not a humidity or moisture meter. It estimates how favorable current conditions are for drying laundry from current weather data or manually entered temperature, humidity and wind. Use it as a guide for outdoor or indoor drying, thick items and bedding.

天気予報ではありません。将来の天気や乾燥状態は予測せず、実際の乾燥結果は日照、素材、厚み、干す間隔、屋根、時間帯、取り込み時間などで変わります。

This is not a weather forecast. It does not predict future weather or drying, and actual results depend on sunlight, material, thickness, spacing, cover, time of day and retrieval timing.

部屋干しを選んで現在天気を取得した場合も、取得値は屋外の現在気象です。室温・室内湿度・室内の風速が分かる場合は、手動入力へ合わせると室内条件に近い目安になります。

If indoor drying is selected with fetched weather, the fetched values are still outdoor current-weather conditions. If you know indoor temperature, humidity and airflow, use the manual controls for a closer indoor estimate.

      データ処理と保存

      Data handling and storage

      現在地機能を使う場合、ブラウザの位置情報許可が必要です。天気取得時には緯度・経度がOpen-Meteoへ送信されます。手動入力だけの場合、入力値はこのブラウザ内で処理されます。

      Using current location requires browser geolocation permission. Latitude and longitude are sent to Open-Meteo when fetching weather. Manual-only inputs are processed in this browser.

      nw_drymeter_v1 には対象・干し方・気温・湿度・風速・緯度経度などを保存します。言語設定は共通キー nw_lang に保存します。別端末には同期されず、ブラウザデータ削除で消えます。

      nw_drymeter_v1 stores target, method, temperature, humidity, wind and coordinates. Language is stored in nw_lang. They do not sync across devices and are removed when browser data is cleared.

      部屋干し・布団の注意

      Indoor drying and bedding notes

      部屋干し結果は、部屋の広さ、換気、除湿機、サーキュレーター、洗濯物の量、干す間隔で変わります。高湿度時はカビ・臭いのリスクにも注意してください。取得天気を使う場合は屋外の現在気象なので、室内実測値がある場合は手動入力を優先してください。

      Indoor drying depends on room size, ventilation, dehumidifiers, air circulators, load size and spacing. High humidity can increase mold and odor risk. Fetched weather is outdoor current weather, so use manual values when indoor measurements are available.

      布団や寝具は素材、厚み、干す面、取り込み時間で変わります。湿ったまま収納しないでください。

      Bedding depends on material, thickness, exposed side and retrieval time. Do not store bedding while it is still damp.

      よくある質問

      FAQ

      実際に乾くか保証できますか？Can this guarantee actual drying?

      いいえ。気温・湿度・風速・降水・雲量からの簡易目安です。日照、素材、干し方、時間帯で変わります。

      No. It is a simple guide based on temperature, humidity, wind, precipitation and cloud cover. Sunlight, material, drying method and time of day can change the result.

      現在地は必須ですか？Is current location required?

      必須ではありません。緯度経度で取得するか、手動入力だけでも使えます。

      No. You can fetch by coordinates or use manual inputs only.

      雨や雲量も見ていますか？Does it consider rain and cloud cover?

      天気取得時は、降水量と雲量を補正に使います。手動入力のみの場合は未考慮です。

      When weather data is fetched, precipitation and cloud cover are used as adjustments. Manual-only mode does not include them.

      天気予報として使えますか？Can I use this as a weather forecast?

      いいえ。Open-Meteoから取得する現在条件、または手動入力した条件を使う現在時点の目安です。将来の天気や乾燥状態は予報しません。

      No. It uses current conditions from Open-Meteo or your manual inputs. It does not forecast future weather or future drying conditions.

      入力内容は保存されますか？Are inputs saved?

      対象、干し方、気温、湿度、風速、緯度経度などはこのブラウザのlocalStorageに保存されます。

      Target, method, temperature, humidity, wind and coordinates are saved in this browser's localStorage.
