Dry Meter: Guide

Use current temperature, humidity, wind, and weather to check how favorable conditions are for drying laundry.

What it does

  • Fetches current weather from Open-Meteo using your current location or entered coordinates
  • Also works with manually entered temperature, humidity, and wind without fetching weather
  • Supports Laundry / Thick items / Bedding and Outdoor / Indoor drying modes
  • Shows a Dry Score from 0 to 100, key reasons, and practical guidance for each use case
Open the tool 日本語ガイド

Use this when

  • You want to check whether laundry is likely to dry well if you start now
  • You are deciding whether to dry thick clothing or bedding outside
  • You know your indoor temperature, humidity, and airflow and want a rough indoor-drying guide

Dry Meter is not a humidity meter or moisture meter. It estimates drying conditions.

How to use

  1. Set current conditions by using your location, entering coordinates, or using the manual controls.
  2. Choose Laundry, Thick items, or Bedding.
  3. Choose Outdoor or Indoor drying.
  4. Read the Dry Score and reasons. 70+ means easier drying, 40–69 average, and 39 or less harder to dry.
  5. Review the practical guidance and copy the result if needed.

Data handling and storage

  • Using current location requires browser geolocation permission.
  • When weather is fetched, latitude and longitude are sent to Open-Meteo. Manual-only use does not call the weather API.
  • Target, method, temperature, humidity, wind, and coordinates are stored in this browser's localStorage.
  • Stored settings do not sync to other devices and disappear when browser data is cleared.

Notes and limits

  • This is not a weather forecast. It uses current fetched conditions or your manual inputs.
  • If you select Indoor while using fetched weather, the fetched values are still outdoor current weather. Prefer manual indoor measurements when available.
  • Actual drying also depends on sunlight, material, thickness, spacing, ventilation, dehumidifiers, and retrieval time.
