## Interpretation

- **PASS:** documented and no audited deficiency found.
- **FIX:** implementation exists but at least one common-contract or functional-test gap is recorded.
- **BLOCKED:** implementation evidence required for evaluation is unavailable.
- **NEEDS_DECISION:** repository evidence cannot resolve a product-contract decision.

## Recommended Wave 1 repair set

Ranked first by number/severity of observed gaps, then by the ability to reuse narrowly scoped fixes without redesigning the tools:

1. **Responsive + help/test cluster:** `earth-alerts`, `earth-timeseries`, `url-title-collector`. These are the only tools with incomplete responsive evidence and also have FAQ/test gaps; fix responsive behavior according to each tool's documented layout class, not a shared fixed width.
2. **Kanji workflow shared-contract cluster:** `old-document-kanji-highlighter`, `old-kanji-ocr-scanner`, `place-old-kanji-checker`, `unicode-kanji-checker`, `variant-kanji-compare`, `name-old-kanji-checker`. These closely related tools share missing help/FAQ/test coverage; five also lack donation evidence, making a carefully reviewed shared-root-cause wave efficient.
3. **General high-gap cluster:** `message-generator`, `habit-plan-generator`, `mini-game-utility`, `newsletter-kit-generator`, `og-image-maker`. Each has four or five gaps centered on usage/FAQ/tests, with `message-generator` also missing donation evidence.

This exact 14-tool set should be Wave 1. Repair plans must preserve each tool's language and layout contracts, validate ad placement, and add behavior-level tests rather than presence-only assertions.
